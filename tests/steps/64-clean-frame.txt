# The clean frame for filming (F2, dev command `clean`): one switch takes the interface out of the picture, the game's
# and the mod's, while Rania's hands, the wheel, the lever, the coffee, Camus, the cockpit and its mirrors stay.
# CleanFrameKeepDialogue (on by default) keeps the game's line where it shows. The flat run is 65-clean-frame-flat.
#
# `clean check <label>` logs every piece at that moment and ends in "-> clean check ok" (on), "-> clean check ok (all
# back)" (off) or "-> clean check FAILED: <what>", naming anything still drawn (a HUD piece, the radar, the wrist, the
# laser, the vignette...). `clean watch <s> <label>` checks every frame for s seconds (flight, passage, getting out,
# boarding) and ends in "-> clean watch ok". Calls (see 62-call): kept, the game's box shows once; hidden, no box
# anywhere and the call still ends normally ("-> call watch ok"). The waitlogs at the end check all of it.
#
# Captures (capture = headset window, mirror = game window):
#  64-rest-before / 64-rest-clean: everything up (HUD, radar, minimap, district sign, wrist, vignette), then the same
#    moment with none of it, the hands, wheel, lever, coffee, Camus and mirrors still there.
#  64-call-kept: only the game's line ahead above the dashboard. 64-call-hidden: no box anywhere.
#  64-spectator-clean: the spectator view, clean too. 64-passage-black: just black, no passage card.
#  64-onfoot-clean: no minimap, money, fuel, jobs, wrist or prompts. 64-onfoot-look: an item looked at, no glow.
#  64-menu: the pause menu as usual. 64-off-hudhidden: off, but the game's own HUD toggle still hides the HUD.
#  64-off: everything back at once, the wrist's last line "Filming  clean frame off".
