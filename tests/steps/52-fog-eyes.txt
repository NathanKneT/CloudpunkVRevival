# but each headset eye has its own off-centre one, so the fog came out thicker in one eye than the other. The fix
# rewrites the fog's direction vectors for each eye. `fx eyes off` puts the game's vectors back, `fx pp GlobalFog off`
# removes the fog (the reference).
# The null headset's eyes share one centred frustum, so there the fog looks the same with or without the fix.
# `fx eyes fake 8 63 4` gives it real headset eyes (frustums turned 8 deg outward, 63 mm apart, 4 deg more down than
# up, made-up values) so the bug shows. Title, cockpit, then on foot.
#
