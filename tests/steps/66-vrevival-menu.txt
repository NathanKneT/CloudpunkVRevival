# The VREVIVAL settings menu, driven like a player: the laser on the entry and on a value's half (`vrsettings point`),
# the d-pad (`press DPadDown|DPadLeft`, the game's own row input), the stick (`vrstick`), Circle (`vrpress back`) and
# the pause button (`vrpress menu`). `vrsettings set` first puts the values the run starts from.
#
# 1. Main menu: the waitlog stops the run unless VREVIVAL sits between the game's OPTIONS and CONTROLS, and
#    `vrsettings check title` ends in "-> vrsettings check ok". 66-title-entry: same font, size and spacing as the rest.
# 2. Opened by the laser. 66-title-window: titled VREVIVAL, amber headers, rows like the game's OPTIONS, WHEEL
#    SENSITIVITY selected with its note under the list, "rows 15 of 15 in the picture". MENU SIGN off then on with
#    the laser ("Menu sign: off", "Menu sign: on again"), then Circle closes it.
# 3. In the cockpit, from the pause menu (66-pause-entry: RESUME, OPTIONS, VREVIVAL, CONTROLS, QUIT).
# 4. Stick right on WHEEL SENSITIVITY: "QUICK (35) -> RELAXED (50)", saved, and `wheel lock` says 50.
# 5. D-pad down twice skips the headers to COMFORT VIGNETTE, d-pad left: NORMAL -> LIGHT.
# 6. The laser on HUD DISTANCE's right half: 2.0 M -> 2.5 M. 66-window-changed shows all three changes.
# 7. Circle, then the game's own OPTIONS by the laser: its own window as before, a row stepped on and back.
# 8. VREVIVAL again, then the pause button closes both ("closed with the game's menu").
# 9. `vrsettings check after`: the HUD now 2.5 m away (66-hud-after). 10. RESUME still closes the pause menu.
# No "VRevival menu:" warning, no "NOT SAVED", no "NOT IN THE FILE", no "check FAILED".
