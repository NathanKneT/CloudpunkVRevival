# Filming tool, not a pass/fail test: district trips to scout shots, flat. `goto <scene> [exit]` borrows one of the
# game's passages, points it at that scene for one trip and runs the game's own PlayerCar.EnterLift on it; `spots`
# writes the district's parking volumes, passages, exits, spawn points, sectors, artist cameras and traffic lanes to
# CloudpunkVR-shots\spots-<scene>.json, which the harness copies to tests\captures\spots-<time>\.
# Needs a save that starts flying in Clearwater (Level0_Right): bring your own save (a folder of .sav files) with
# -SaveFixture <folder>.
#   tools\test\Run-VRTest.ps1 -Steps tests\steps\tools-and-probes\69-district-goto.txt -NoHeadset -SaveFixture <folder>
# Four trips, each a different case: Level4 (a passage pointed there, no exit asked), Level2_Midtown (the game's own
# trip), Level3 99 (an exit Level3 doesn't have, so it arrives at one it has), Level0_Middle 11 (pointed there, exit
# 11). Then `park` by index and by name, and two refusals that move nothing. Districts the save hasn't reached yet may
# start story lines or calls.
# The harness writes CloudpunkVR.bench, so the mod blocks every Steam achievement for the run; the run stops at the
# first step unless all three hooks are on.
#
# Check: "goto: arrived in <scene>" per trip, no "goto FAILED", no "goto: stopped"; a "spots:" line and a file in each
# of the five districts (cameras with a sane fov and a "key" each, lane points about 10 m apart). "achievement ...
# blocked (bench)" lines are fine, but both `unitylog` steps must count 0 "UnlockAchievement:" lines (the game's own
# unlock never ran), and the last `bench` line lists what was blocked.
# Mirror captures: 69-<scene>.png a few seconds after each arrival, the HOVA out of the exit in the new district.
