# The spectator view (F8, dev command `spectator`): instead of Unity's shaky mirror of the left eye, the game's window
# shows that eye's finished image cropped, smoothed and level, for recording. The headset's own image doesn't change
# (the `capture` steps look the same with the view on and off).
# The null headset never moves, so `spectator shake 2` adds a hand-held head shake on top of its tracking.
# A: at rest, raw mirror then the view. B: the cost, view off and on, twice. C: the shake at rest, raw mirror vs the
# view, a 6 s trace, then a pixel check on a patch of dashboard (head still, then shaking about the eye: "head
# shaking" should stay within half a pixel of "head still"). D: turning in place (no throttle, a crash would shake the
# cockpit), then both hands on the wheel. E: the coffee held up, Camus. F: the formats and a too-wide fov. G: off and
# on like the key. H: the pause menu. I: a district passage. J: on foot. K: back in the HOVA. L: off.
#
# Check: the waitlogs at the end fail the run if a trace wasn't at least 3x steadier than the head, leaned or showed an
# edge ("spectator check: steadier, level, no edge"), or if a black period was missed ("black with the headset for").
# The "perf spectator-off" / "perf spectator-on" lines give the cost.
